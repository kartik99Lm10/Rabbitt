# Talking Rabbitt 🐰

Talking Rabbitt is a conversational analytics tool that allows users to ask questions about their CSV data and receive answers with automatic visualizations.

## Features

- Upload CSV files
- Ask questions in natural language
- AI generates insights
- Automatic charts when useful

## Setup

1. Install dependencies

pip install -r requirements.txt

2. Set your Groq API key

export GROQ_API_KEY="your_key_here"

3. Run the app

streamlit run app.py
